# 🌙 Deenly

> Your daily companion for a stronger connection with Allah.

Deenly is a modern Islamic mobile application designed to help Muslims stay connected to their faith through prayer reminders, Quran reading, dhikr, Islamic content, and daily spiritual growth tools—all in one beautiful and easy-to-use experience.

---

## 🛠️ Tech Stack

- **APIs**:
  - [Al Adhan API](https://aladhan.com/islamic-calendar-api) – Prayer times and Islamic calendar data
  - [Quran API – optional] – Verse rendering and translation
- **Icons**: [Lineicons](https://lineicons.com/free-icons) – Clean, modern icon set
